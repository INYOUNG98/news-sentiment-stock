# 뉴스 감성분석을 활용한 주가 방향 예측

경제 뉴스 헤드라인의 감성 점수가 다음 날 주가 등락과
관련이 있는지 확인해본 프로젝트입니다.

## 1. 프로젝트 개요
- 증권사에서 근무하면서 뉴스가 주가에 미치는 영향을
  데이터로 직접 확인해보고 싶어 시작했습니다.
- 기간: 2026년 7월, 약 7주
- 사용 도구: Python (Google Colab), pandas, KoNLPy,
  scikit-learn, FinanceDataReader

## 2. 데이터
| 구분 | 내용 |
|------|------|
| 뉴스 | 네이버 증권 API, 풀무원(017810) 헤드라인 1,125건 |
| 기간 | 2025.09 ~ 2026.07 (약 10개월) |
| 주가 | FinanceDataReader 일봉 데이터 |
| 최종 | 뉴스·주가 병합 191일 데이터셋 |

처음에는 삼성전자로 시작했으나, 뉴스가 하루 300건 이상이라
수집 가능한 기간이 6일에 불과했습니다. 분석 기간을 확보하기
위해 뉴스량이 적당한 중형주(풀무원)로 변경했습니다.

## 3. 분석 과정
1. 뉴스 수집: HTML 크롤링이 페이지 구조 변경으로 실패하여
   모바일 증권 API(JSON) 호출 방식으로 전환
2. 감성 점수: KNU 한국어 감성사전으로 헤드라인별 점수 산출,
   날짜별 평균 집계
3. 상관분석: 당일 감성 점수와 익일 수익률의 상관관계 확인
4. 분류 모델: 익일 상승/하락을 예측하는 모델 비교
   (시계열 특성을 고려해 shuffle 없이 앞 80% 학습, 뒤 20% 평가)

## 4. 결과
- 감성 점수와 익일 수익률의 상관계수 0.215 (p=0.003)

| 모델 | 정확도 | F1 |
|------|--------|-----|
| 로지스틱 회귀 | 0.658 | 0.133 |
| 로지스틱 회귀 (balanced) | 0.605 | 0.516 |
| Random Forest (balanced) | 0.605 | 0.400 |

첫 모델은 정확도가 가장 높았지만 혼동행렬을 확인한 결과
대부분을 '하락'으로만 예측하고 있었습니다. 평가 구간이
하락장이라 생긴 착시로, 실제로 모든 날을 하락이라고 해도
같은 정확도가 나옵니다. 클래스 불균형을 보정한 모델은
정확도는 낮아졌지만 상승일 13일 중 8일을 맞혀 F1 기준으로
가장 나은 성능을 보였습니다.

## 5. 한계 및 개선 방향
- 사전 기반 감성분석은 문맥을 반영하지 못합니다. 실제로
  파업 관련 부정 기사가 긍정(+2)으로 분류되는 사례를
  확인했습니다.
- 장 마감 후 시황 기사가 포함되어 있어, 감성이 주가를
  예측했다기보다 주가가 뉴스 감성에 반영됐을 가능성
  (역인과)을 배제할 수 없습니다.
- 분석 기간이 10개월로 짧고 단일 종목이라 일반화에 한계가
  있습니다.

## 6. 향후 계획
- 사전 방식의 한계를 보완하기 위해 문맥을 반영하는
  딥러닝 기반 감성분석(KoBERT 등)을 적용해 더 깊이 있는
  분석을 해보고 싶습니다.
- 단일 종목이 아닌 여러 종목·업종으로 확장해 감성과
  주가의 관계가 종목 특성에 따라 달라지는지 확인하고
  싶습니다.
- 이런 분석을 체계적으로 배우기 위해 대학원 진학을
  준비하고 있습니다.
